# i18n (Internationalisation)

## Supported Languages

| Code | Language |
|------|----------|
| `en` | English (default) |
| `nl` | Nederlands (Dutch) |
| `fr` | Français (French) |

## Setup

`packages/i18n` provides the i18n setup:

```typescript
import { createI18n, setSharedI18n, getSharedI18n } from "@mity-garden/i18n";

// Initialize once at app startup
const i18n = createI18n({ locale: "en" });
setSharedI18n(i18n);

// Later, in any file
const i18n = getSharedI18n();
```

## Translation Files

Translations are in `packages/i18n/src/locales/{locale}/common.json`.

Key structure:
```json
{
  "app": { "name": "mITyGarden", "tagline": "..." },
  "nav": { "home": "...", "newProject": "..." },
  "wizard": {
    "title": "...",
    "steps": {
      "location": "...",
      "boundary": "...",
      "dimensions": "...",
      "style": "...",
      "goals": "..."
    }
  },
  "canvas": { ... },
  "assetLibrary": { ... }
}
```

The wizard step order (spec 003) is: **Location → Boundary → Dimensions → Style → Goals**.

## Adding a New Language

1. Create `packages/i18n/src/locales/{code}/common.json`
2. Copy from `en/common.json` and translate all values
3. Add the locale code to `SupportedLocale` type in `packages/i18n/src/index.ts`
4. Add to `LOCALE_LABELS` map
5. Import and register in `createI18n()`

## Usage in Components

```typescript
import { useTranslation } from "react-i18next";

function MyComponent() {
  const { t } = useTranslation("common");
  return <h1>{t("app.name")}</h1>;
}
```

## Changing Locale at Runtime

```typescript
import { useUiStore } from "@mity-garden/shared-ui";

function LanguageSwitcher() {
  const setLocale = useUiStore(s => s.setLocale);
  return <button onClick={() => setLocale("nl")}>NL</button>;
}
```

`uiStore.setLocale()` updates both the Zustand state and calls `i18n.changeLanguage()`.
